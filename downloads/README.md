# Oche Club test downloads

The first Android test build and installable web export are included here so you can download them directly from GitHub.

- [Download Android test APK](https://github.com/Pigeonhunt3r/Dart-app/raw/refs/heads/main/downloads/v1.0.0-alpha.1/OcheClub-1.0.0-debug.apk)
- [Download web ZIP](https://github.com/Pigeonhunt3r/Dart-app/raw/refs/heads/main/downloads/v1.0.0-alpha.1/OcheClub-web.zip)
- [SHA-256 checksums](v1.0.0-alpha.1/SHA256SUMS.txt)
- [Test notes and limitations](v1.0.0-alpha.1/README.md)

For Android, open the APK on your phone to install it. It is a debug development build for personal testing. It still needs real-phone testing and publisher-controlled release signing before commercial distribution.

The web ZIP must be hosted on HTTPS before it can be installed through a browser on Android or via Safari's Add to Home Screen on iPhone. A native iPhone application and IPA will be added in a later phase.

Future successful alpha-tag builds can publish downloads on the [GitHub Releases page](https://github.com/Pigeonhunt3r/Dart-app/releases). Check the [Actions page](https://github.com/Pigeonhunt3r/Dart-app/actions) for build/release status. The versioned downloads in this directory do not depend on that workflow succeeding.

There are no signing keys, passwords, SDK caches or local browser data in these downloads. Debug builds from different machines may have different signing keys; uninstalling an older debug build can be necessary and deletes its local match data.
